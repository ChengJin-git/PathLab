## CONFIGURATION REFERENCE

### Task & Data
**task_type**: classification, survival_prediction
**data_level**: wsi, patch (MUST match dataset's data_type!)

### Preprocessing (Tiling)
**tile_size**: 256, 512, 1024 (default: 512)
**stride**: 0 = non-overlapping (default), or set to tile_size/2 for 50% overlap
**pyramid_level**: 0 = highest resolution (default), 1 = 2x downsampled, 2 = 4x downsampled

### Feature Extraction
**encoder** (17 available): resnet50, vit_l_16, conch, conch15, uni, uni2, virchow, virchow2, phikon, phikon2, plip, patho_clip, openmidnight, H-Optimus-0, H-Optimus-1, mSTAR, GPFM
**feature_batch_size**: 64 (default), increase for faster extraction if GPU memory allows (128, 256)

### Tissue Segmentation (WSI only)
**sthresh**: saturation threshold, 8 (default), lower for pale tissues
**mthresh**: median filter threshold, 7 (default)
**close**: morphological closing kernel, 4 (default), increase for tissue with holes
**use_otsu**: false (default), set true for automatic thresholding

### Model Training
**aggregator** (8 available, for wsi only): abmil, meanmil, maxmil, dsmil, dtfdmil, clam_sb, clam_mb, transmil
**learning_rate**: 0.0001 (default)
**epochs**: 50 (default)
**batch_size**: 1 for wsi, 64 for patch
**optimizer**: adam (default), sgd, adamw
**auto_balance**: true (recommended for imbalanced classes), false (for balanced classes)
**early_stopping_patience**: 10 (default), increase for small datasets, decrease for large datasets

## DATA SPLIT REQUIREMENTS (CRITICAL)

Before generating [TASK_CONFIG], you MUST verify the dataset has enough samples:

**For Random 7:1:2 Split** (default):
- Each class needs at least **10 samples** (because val is 10%, need 1 sample per class in val)
- Minimum total = num_classes × 10 (e.g., 2 classes = 20 samples, 3 classes = 30 samples)
- If dataset is too small, suggest K-Fold instead

**For K-Fold Cross-Validation**:
- Each class needs at least **K samples** (where K = number of folds)
- For 5-fold: each class needs ≥5 samples
- For 3-fold: each class needs ≥3 samples
- Maximum K = minimum samples per class

**Examples**:
- Dataset with 8 slides (4 per class) → Can use 4-fold max, NOT 5-fold, NOT random split
- Dataset with 15 slides (7 vs 8) → Can use 7-fold max, NOT random split (needs 10 per class)
- Dataset with 25 slides (12 vs 13) → Can use random split OR up to 12-fold

**When dataset is too small**:
1. Inform user about the limitation
2. Suggest using K-Fold with smaller K value
3. Or suggest adding more samples
