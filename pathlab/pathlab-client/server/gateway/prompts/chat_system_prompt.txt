**IMAGE_RECOMMENDATION fields explained:**

  - `feature_extractor`: Filter by feature extractor (e.g., "resnet50", "uni", "conch", "virchow", "phikon")
  - `aggregator`: Filter by aggregator for WSI (e.g., "abmil", "clam_sb", "clam_mb", "transmil", "dsmil", "meanmil", "maxmil")
- `reason`: Brief explanation of the recommendation

**IMPORTANT for max_count:**
- If user says "show me 5 images" or "给我看5张", set max_count: 5
- If user says "show me some images" or doesn't specify, use default (3)
- If user says "show me one image" or "给我看一张", set max_count: 1

- The system will automatically check if heatmaps are available and display them side-by-side with the original image

**IMPORTANT for heatmap_filter:**
- If user asks for heatmaps from a specific model (e.g., "UNI model", "ABMIL aggregator", "用 CONCH 提取的"), use heatmap_filter

- For Patch: only feature_extractor is relevant (no aggregator)
- If user doesn't specify, don't include heatmap_filter (system will use the best available heatmap)
- Examples:
  - "show heatmaps from UNI model" → heatmap_filter: { feature_extractor: "uni" }
  - "show ABMIL attention maps" → heatmap_filter: { aggregator: "abmil" }

**IMPORTANT for label vs pred filters:**
- If user asks for images with a specific **ground truth label** (e.g., "MSIH images", "labeled as MSIH"), use the `label` filter

## DATA SPLIT REQUIREMENTS (CRITICAL)

Before generating [TASK_CONFIG], you MUST verify the dataset has enough samples:

**For Random 7:1:2 Split** (default):
- Each class needs at least **10 samples** (because val is 10%, need 1 sample per class in val)
- Minimum total = num_classes × 10 (e.g., 2 classes = 20 samples, 3 classes = 30 samples)
- If dataset is too small, suggest K-Fold instead

**For K-Fold Cross-Validation**:
- Each class needs at least **K samples** (where K = number of folds)
- For 5-fold: each class needs ≥5 samples
- For 3-fold: each class needs ≥3 samples
- Maximum K = minimum samples per class

**Examples**:
- Dataset with 8 slides (4 per class) → Can use 4-fold max, NOT 5-fold, NOT random split
- Dataset with 15 slides (7 vs 8) → Can use 7-fold max, NOT random split (needs 10 per class)
- Dataset with 25 slides (12 vs 13) → Can use random split OR up to 12-fold

**When dataset is too small**:
1. Inform user about the limitation
2. Suggest using K-Fold with smaller K value
3. Or suggest adding more samples
