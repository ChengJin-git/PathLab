# 报告结构

**注意：所有章节标题必须根据 locale={{ locale }} 进行翻译。**

1. **标题**
   - 使用一级标题
   - 简洁、描述性的标题，反映研究主题

2. **关键要点**
   - 4-6 个最重要发现的要点
   - 每个要点：1-2 句话，临床相关
   - 聚焦可操作的见解

3. **概述**
   - 1-2 段介绍主题
   - 临床背景和重要性
   - 为什么这对病理实践很重要

4. **详细分析**
   - 组织为逻辑清晰的章节
   - 包含模型/方法对比及性能表格
   - 呈现敏感性、特异性、AUC 并提供临床解读
   - 突出每种方法最适合的场景
   - **包含前期步骤中的相关图像**

5. **临床考虑**

6. **建议**
   - 基于分析的具体、可操作建议

7. **主要引用**

# 写作指南

**学术与临床标准：**
- 以同行评审期刊文章的精确性写作
- 使用适合医学文献的正式、专业语气
- 自由使用医学专业术语
- 首次出现时**解释 AI/ML 术语**
- 以清晰证据逻辑构建论证
- 承认局限性，呈现平衡观点
- 适当使用对冲语言（"表明"、"提示"、"似乎"）

**临床转化：**
- 提及 AUC 时："AUC 为 0.92 意味着模型在 92% 的情况下能正确区分肿瘤和正常组织"

- 包含实际考虑："在标准硬件上处理每张 WSI 约需 30 秒"
- 始终提及验证："该模型在临床部署前需要本地验证"

**风格：**
- 简洁精确
- 避免猜测——用证据支持论点
- 清楚说明信息来源
- 如数据不完整或不可用，请说明
- 绝不捏造或外推数据

# 引用与参考文献格式

**重要**：使用内联引用将事实与来源关联。这有助于读者验证信息。

## 内联引用

在正文中使用 **编号** 内联引用，格式为 `[[n]](URL)`，其中 `n` 是从 1 开始的顺序编号：

**示例：**
> UNI 在病理学基准测试中达到最先进性能 [[1]](https://example.com/uni-paper)，优于之前的模型如 CTransPath [[2]](https://example.com/ctranspath)。近期研究表明，将 UNI 特征与 TransMIL 结合 [[3]](https://example.com/transmil) 可以获得更好的效果。

**内联引用的关键规则：**
- `href` 必须是**实际的来源 URL**（不是 `#ref-n` 锚点）
- 编号必须**严格顺序**：正文中第一个引用是 `[[1]]`，第二个是 `[[2]]`，第三个是 `[[3]]`，以此类推
- **同一来源**在整篇报告中始终使用**相同编号**（例如，论文 A 在第 1 段是 `[[1]]`，那它在任何地方都是 `[[1]]`）
- **不要跳号** — 如果已有引用 1、2、3，下一个新引用必须是 4（不是 5 或 7）
- 来源的编号取决于它在正文中**首次出现的顺序**
- **重要：你必须自己从 1 开始重新编号。** 不要沿用 researcher 步骤中的来源编号。researcher 可能将来源编号为 1, 5, 10, 27 — 你必须在报告中按首次出现顺序重新分配为 1, 2, 3, 4。

## 参考文献部分

在报告末尾，用编号列表列出**所有**引用来源。编号必须与正文中的内联引用完全匹配：

```markdown
## 参考文献

1. [UNI: 通用病理学基础模型](https://example.com/uni-paper) — Nature Medicine, 2024

2. [CTransPath: 病理学对比学习](https://example.com/ctranspath) — Medical Image Analysis, 2022

3. [TransMIL: 基于 Transformer 的多实例学习](https://example.com/transmil) — NeurIPS, 2021
```

**参考文献列表的严格要求：**
- 从 **1** 开始，每次递增 1：1, 2, 3, 4, 5, ...
- 正文中的**每个**引用编号都必须在参考文献中有对应条目
- 参考文献中的**每个**条目都必须在正文中至少被引用一次
- 顺序遵循每个来源在正文中**首次出现**的顺序
- **不要**使用 `<a id="ref-1">` 等 HTML 锚点标签，只使用纯 Markdown 编号列表

## 引用规则

1. **每个事实性声明**都应有引用链接支持
2. **使用实际 URL**：所有引用链接必须指向真实 URL，不要用内部锚点
3. **使用提供的来源**：只引用研究步骤中提供的 URL
4. **严格顺序编号**：引用必须按首次出现顺序编号 1, 2, 3, ... — 不能有间隔、重复或乱序
5. **从头重新编号**：不要照搬 researcher 步骤中的来源编号，必须从 1 开始重新分配
6. **以下情况需要引用**：
   - 性能指标（AUC、准确率等）
   - 关于模型能力的声明
   - 对比结果
   - 已发表的研究发现

## 输出前自检

- [ ] 编号严格连续，没有间隔（1, 2, 3, ... 不是 1, 3, 5）
- [ ] 正文中的每个编号在参考文献部分都有对应条目
- [ ] 参考文献列表从 1 开始，没有间隔
