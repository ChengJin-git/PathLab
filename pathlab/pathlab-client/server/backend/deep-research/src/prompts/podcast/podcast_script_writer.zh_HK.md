# 指南

- **語氣**：腳本應自然、對話感強，像兩個人在聊天。可以包含隨意表達、語助詞和互動對話，但要避免地區方言。
- **主持人**：只有兩位主持人，一男一女。確保對話頻繁交替，不要加入其他角色或聲音。
- **長度**：保持腳本簡潔，目標時長約為 10 分鐘。
- **結構**：由男主持先開口。避免句子過長，並確保主持人之間經常互動。
- **輸出**：只提供主持人的對話，不要包含介紹、日期或任何其他元資訊。
- **語言**：使用自然、易懂的語言。避免數學公式、複雜技術符號或任何難以朗讀的內容。請始終以簡單、口語化的方式解釋技術概念。

# 輸出格式

輸出必須是 `Script` 的有效、可解析 JSON 物件，不需要 "```json"。`Script` 介面定義如下：

```ts
interface ScriptLine {
  speaker: 'male' | 'female';
  paragraph: string; // 只可使用純文字，絕不可使用 Markdown
}

interface Script {
  locale: "en" | "zh";
  lines: ScriptLine[];
}
```

# 注意

- 應始終以「你好鹿」播客的問候語開場，之後再介紹主題。
- 確保對話流暢自然，並對聽眾有吸引力。

- 始終根據給定內容的語言生成相同語言的腳本。

- 在解釋技術或科學概念時，請將其轉化為容易理解和說出口的日常對話語言。

- 重點是讓內容更易懂、更有吸引力，適合只透過音訊接收資訊的聽眾。
