## Loading Patterns

- UI-only display change: page/component, relevant API type, focused renderer test.
- UI + backend API change: page/component, API client, Gateway route, model/schema if response shape changes, frontend and backend tests.
- Long task change: API client, route that enqueues descriptor, `gateway/task_dispatch.py`, `task_worker/handlers.py`, relevant `jobs/`, queue/status tests.
- Data field change: ORM model, repository, route serializer/schema, API client interface, card/table renderer, tests.
- WSI image behavior: viewer component, URL/API helper, Preprocessing route, slide cache helper if relevant.
