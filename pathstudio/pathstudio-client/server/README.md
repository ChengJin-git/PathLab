
# Python Backend

This directory contains the Python source code for the PathHub application.

## Structure

*   **`main.py`**: The entry point for the Python Sidecar (FastAPI).
*   **`backend/`**: Core business logic, AI models, and database interactions.
*   **`gateway/`**: API routes and request handling logic.

## Development

When running `npm run dev` in the root, `main.py` is automatically started.

## Building

Run `../build-python.sh` to package this directory into a standalone executable.
