# PathStudio API contracts

Base URL (via Nginx): /PathStudio/api/

## Gateway (6100)
- GET /health → { status: "ok", service: "gateway" }
- GET /wsi → { items: WsiSummary[] }
- GET /wsi/{wsi_id} → { wsi_id, meta, last_run? }
- POST /tasks/wsi_classification { wsi_id, params } → { task_id, status }
- GET /tasks/{task_id} → { task_id, status, progress? }
- GET /results/{wsi_id} → { wsi_id, pred, probs, attention_index? }  (P0: probs is a map { label: number })

## Preprocessing service (6101)
- GET /health → { status: "ok", service: "preprocessing" }
- GET /api/wsi → { items: WsiSummary[] }
- GET /api/wsi/{wsi_id}/dzi → DZI XML or JSON descriptor
- GET /api/wsi/{wsi_id}/tiles/{z}/{x}_{y}.jpeg → JPEG bytes

## AI service (6102)
- GET /health → { status: "ok", service: "ai" }
- POST /api/ai/analyze { task:"wsi_classification", wsi_id, params } → { task_id, status }
- GET /api/ai/tasks/{task_id} → { task_id, status, progress? }
- GET /api/ai/results/{wsi_id} → { wsi_id, pred, probs, attention_index? }

## Types
- WsiSummary: { wsi_id: string, label?: string, wsi_path?: string, mpp?: number, vendor?: string }
- Ingestion CSV: either minimal (dir, case_id, slide_id, label[, ext]) with derived wsi_path:
  - If slide_id includes an extension → wsi_path = dir + "/" + slide_id
  - Else → wsi_path = dir + "/" + slide_id + "." + (ext per-row > default_ext param > "svs")
  - Or extended (dir, case_id, slide_id, label, wsi_path) where wsi_path takes precedence if present
  - Ingestion accepts an optional parameter default_ext (e.g., "svs") used when per-row ext is absent
- params for wsi_classification (defaults for 3090x1):
  - tile_size: number = 256
  - stride: number = 256
  - feature_model: "resnet50_imagenet" (P0) | "gpfm" | "mstar" | etc
  - aggregator: "mean" (P0) | "attention_mil"
  - batch_size: number = 64 (adjust by VRAM)
  - device: "cuda" (fallback to "auto"|"cpu" if unavailable)

## Auth
- Frontend uses JWT for user actions (future), microservices accept internal API key via Nginx header x-internal-api-key (no exposure to client).

## Storage conventions
- **Database (PostgreSQL)**: WSI metadata, AI tasks, AI results (metadata), training tasks, trained models
- **Files**:
  - uploads/ai_results/{wsi_id}/{task_id}_attention.npy — attention weights
  - uploads/models/{model_id}/ — user-trained models
  - uploads/training/{task_id}/features/ — training features
  - uploads/thumbnails/{wsi_id}.jpeg — generated by Preprocessing service
