# Capability fallback artwork

These SVGs come from https://github.com/lucide-icons/lucide/tree/main/icons
(retrieved 2026-11-02). Their stroke color is changed from `currentColor` to
`#475569` for use as standalone images. See the included LICENSE for ISC and
Feather-derived MIT attribution. They are openly licensed, not public-domain logos.

The library selects related images for literature/search, statistics, figures,
presentations, data, writing and pathology, with skill/connector defaults.
Repository-provided logos are stored separately with their source commit and
repository license; displaying a logo does not assert that its trademark is public domain.
